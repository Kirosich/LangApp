# LangApp — контекст для Claude Code

## Кто пользователь и зачем это приложение
Личное приложение для изучения казахского (A2, активное освоение) и
английского (B2, поддержание уровня). Испанский — фоновый, третий язык
(~30 слов), не приоритет.

## Стратегия обучения (важно соблюдать при генерации любого контента)
- Слова и фразы группируются ПО ТЕМАМ (еда, природа, числа/время, бытовое,
  глаголы), а НЕ парами "казахское слово = английское слово". Прямое
  парное сопоставление двух языков создаёт интерференцию и не используется.
- Английский используется только как точечная мнемоническая опора — если
  есть реальное фонетическое или лексическое сходство с казахским словом.
  Не создавай карточки специально "для сравнения" языков.
- Казахского контента (диалогов, фраз, примеров) в открытом доступе мало —
  при добавлении карточек старайся сразу давать транскрипцию и пример
  использования в предложении, не только голый перевод.

## Форматы упражнений
- SRS по SM-2 — интервалы считаются в server/srs/sm2.js
- Три типа квиза: multiple choice, typing (с толерантностью к опечаткам,
  Левенштейн ≤1), matching pairs
- При запросе "сделай упражнения на тему X" — сначала проверь, есть ли уже
  карточки с этой темой в БД, не дублируй, добавляй только новое

## Что важно трекать
- сколько карточек выучено / осталось на сегодня
- streak — дней подряд с хотя бы одной завершённой сессией (study/quiz)
- суммарное время, потраченное на упражнения — по дням/неделям (см.
  `study_sessions` в server/db/migrate.js и GET /api/stats)
