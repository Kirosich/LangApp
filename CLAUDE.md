# LangApp — контекст для Claude Code

## Кто пользователь и зачем это приложение
Личное приложение для изучения казахского (A2, активное освоение) и
английского (B2, поддержание уровня). Испанский — фоновый, третий язык
(~30 слов), не приоритет. Работает в маркетинговом агентстве, ведёт побочный
проект эфиргейм.рф (платформа для стримеров/спонсоров, на нём же и живёт этот
langapp) и помогает с TikTok-стримами — эти проекты используются как материал
для примеров на английских занятиях.

### Казахский — self-study, ~2.5 часа/день
20-часовой план из 8 блоков (см. курс "Казахский — грамматика" в разделе
Теория приложения). Методология: сначала пробует конструкции сам, потом
просит проверить (active recall); предпочитает понимать логику грамматики
(корни, аффиксы, падежи, маркеры времени), а не зубрить; работает по
чек-листам. Ресурсы: kaz-tili.kz (Валяева, оглавление на in-soderj.htm)
для грамматики, Pimsleur для аудио. Принципы: агглютинативный язык
прогрессирует нелинейно, плато — норма; лучше 2 короткие сессии в день, чем
одна длинная; сон влияет на закрепление. Цели: автоматизм простых
конструкций (~40-50ч суммарно), функциональная речь (~150+ч).

### Английский — структурированный курс грамматики, B2 (самооценка)
20 часов, 5 модулей (см. курс "English Grammar — Elijah" в разделе Теория):
Perfect Tenses (приоритет, 6ч) → Conditionals (4ч) → Articles (4ч) →
Prepositions (3ч) → свободная практика (3ч). Слабые места по диагностике:
Past Perfect (стабильно пропускается), артикли/предлоги (напр. "in the
marketing agency" вместо "at a marketing agency", "a free time" вместо
"free time"), согласование has/have в 3-м лице, согласование this/these,
порядок слов с "already". Подход: объяснять логику, а не только правило;
примеры — из реальных проектов пользователя; при неуверенности замедляться,
не спешить дальше; пользователю нравится, когда дают выбор, что делать
дальше. Дублирующий трекер вне приложения:
/mnt/user-data/outputs/english-grammar-plan-20h.md.

## Стратегия обучения (важно соблюдать при генерации любого контента)
- Слова и фразы группируются ПО ТЕМАМ (еда, природа, числа/время, бытовое,
  глаголы), а НЕ парами "казахское слово = английское слово". Прямое
  парное сопоставление двух языков создаёт интерференцию и не используется.
- Английский используется только как точечная мнемоническая опора — если
  есть реальное фонетическое или лексическое сходство с казахским словом.
  Не создавай карточки специально "для сравнения" языков.
- Казахского контента (диалогов, фраз, примеров) в открытом доступе мало —
  при добавлении карточек старайся сразу давать транскрипцию и пример
  использования в предложении, не только голый перевод.

## Форматы упражнений
- SRS по SM-2 — интервалы считаются в server/srs/sm2.js
- Три типа квиза: multiple choice, typing (с толерантностью к опечаткам,
  Левенштейн ≤1), matching pairs
- При запросе "сделай упражнения на тему X" — сначала проверь, есть ли уже
  карточки с этой темой в БД, не дублируй, добавляй только новое

## Что важно трекать
- сколько карточек выучено / осталось на сегодня
- streak — дней подряд с хотя бы одной завершённой сессией (study/quiz)
- суммарное время, потраченное на упражнения — по дням/неделям (см.
  `study_sessions` в server/db/migrate.js и GET /api/stats)

## Теоретические блоки (грамматика)
Отдельный раздел "Теория" (server/routes/theory.js, client/src/pages/Theory*.jsx)
для грамматики — параллельно вокабуляру на SRS-карточках. Структура:
курс (`theory_courses`) → блоки (`theory_blocks`, со статусом и
план/факт минутами) → пункты-чеклист (`theory_items`, done + notes).
Сид данных в server/seed-theory.js — по умолчанию 2 курса (казахский,
английский) из профилей выше; распределение уже пройденных тем по блокам —
черновое, пользователь может переразложить через UI.
